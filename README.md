# קלורית: מעקב קלוריות בעברית

אפליקציית ווב (PWA) למעקב קלוריות, עם **מאגר המזון הישראלי "צמרת"** של משרד הבריאות.
מותקנת על מסך הבית של הטלפון ועובדת גם בלי אינטרנט. הנתונים נשמרים בטלפון, ואפשר להפעיל סנכרון לענן.

**כתובת האפליקציה:** https://shanimosco47-pixel.github.io/calorie-counter/

## התקנה על Samsung Galaxy S22

1. פותחים את הכתובת למעלה ב-**Chrome**.
2. בראש מסך "היום" מופיע כרטיס **התקנת קלורית בטלפון** ← לוחצים **התקנה** ומאשרים.
3. האייקון "קלורית" יופיע במסך הבית (או במגירת האפליקציות) ויפתח במסך מלא.

לא להשתמש ב-⋮ ← "הוספה למסך הבית": כשמותקנות אפליקציות אחרות מאותו אתר (`shanimosco47-pixel.github.io`),
החלון הזה של Chrome מדווח בטעות "already installed". כפתור ההתקנה באפליקציה עוקף אותו.

## מה יש באפליקציה

| מסך | מה עושים בו |
|---|---|
| **היום** | יעד מול נאכל, חלבון/פחמימות/שומן, 4 ארוחות, הוספה מהירה בלחיצה אחת, מעבר בין ימים |
| **הוספה** | חיפוש בעברית ב-4,500 מזונות ישראליים, כמות בגרמים או במידה ביתית (כף, פרוסה, פיתה...), אחרונים, מועדפים, המזונות שלי |
| **סריקת ברקוד** | חיפוש ב-Open Food Facts. מוצר שלא נמצא: מזינים פעם אחת מהתווית והוא נשמר |
| **היסטוריה** | גרף 7/30 ימים מול היעד, מעקב משקל, מעבר לימים קודמים |
| **הגדרות** | יעד ידני או מחושב (נוסחת Mifflin-St Jeor לפי גיל, גובה, משקל, פעילות ומטרה), סנכרון לענן, ייצוא/ייבוא גיבוי |

## סנכרון לענן

הגדרות ← **סנכרון לענן** ← **הפעלת סנכרון**. האפליקציה יוצרת קוד סודי (24 תווים, 120 ביט אקראי).
כל מכשיר שמזינים בו את הקוד (**יש לי קוד**) מקבל את אותם נתונים: יומן, משקל, מזונות, מועדפים ויעד.
שמרו את הקוד במקום בטוח: הוא המפתח היחיד לנתונים בענן, ואין אפשרות לשחזר אותו.

- **איך זה עובד:** כל שינוי נרשם קודם בטלפון (עובד גם בלי אינטרנט) ונשלח לענן כשיש חיבור. בהתנגשות, העריכה המאוחרת יותר גוברת.
- **שרת:** פרויקט Supabase בשם `kalorit` (פרנקפורט). הטבלה `sync_records` חסומה לגישה ישירה;
  הגישה רק דרך הפונקציות `sync_push` / `sync_pull`, שמזהות את הנתונים לפי SHA-256 של הקוד.
- **לא מסונכרן:** מפתח ה-API של Claude נשאר רק בטלפון.

## מקורות נתונים

- **צמרת**, מאגר הנתונים התזונתיים של משרד הבריאות ([data.gov.il](https://data.gov.il/datasets/ministry-health/nutrition-database)): 4,508 מזונות, מתוכם 4,196 עם מידות ביתיות.
  הקובץ `data/tzameret.json` נבנה מקובצי ה-CSV המקוריים בעזרת `scripts/build_tzameret.py`.
- **Open Food Facts** לברקודים (מאגר פתוח, הכיסוי של מוצרים ישראליים חלקי).

## פיתוח

```bash
npm install
npm run serve          # http://localhost:4173
npm test               # בדיקות יחידה
npx playwright test    # בדיקות מקצה לקצה במידות מסך של S22 (כולל סנכרון בין שני מכשירים)
```

עדכון מאגר צמרת: מורידים את קובצי ה-CSV מ-data.gov.il ומריצים
`python3 scripts/build_tzameret.py <תיקיית ה-CSV>`.

אחרי שינוי בקבצי האפליקציה, מעלים את `VERSION` ב-`sw.js` כדי שהטלפונים יקבלו את הגרסה החדשה.

## בהמשך (סבב 2)

זיהוי מנות מתמונה: צילום ← Claude מזהה פריטים וכמויות ← `matchFood()` מתאים למאגר צמרת ← `confirmItems()` לאישור.
התשתית כבר קיימת; שדה מפתח ה-API נמצא בהגדרות תחת "ניסיוני".
